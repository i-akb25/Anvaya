## Importing authentic questions

Use the `ReviewedQuestionPack` schema in `lib/platform/moderation.ts`. Keep candidate packs outside public Git until redistribution permission and personal-data checks pass. Run:

```sh
node --experimental-strip-types scripts/review-pack.mjs /absolute/path/to/candidate-pack.json
```

The validator rejects missing license permission, named editorial review, source question numbers, final keys, required figures and malformed MCQ/MSQ/numeric answers. A passing schema does not authenticate the claimed reviewer or license. An editor must inspect evidence. No pack is automatically published by this command.

Never convert a diagram question into plain text with its figure missing. Do not turn a link-only official paper archive into a rehosted question bank. Keep each revision and correction traceable. Never pad a short bank through silent repetition or claim a question count based on PDF count.
