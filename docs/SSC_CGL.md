## Daily study and question diagnosis · 18 October 2026

`/ssc-cgl/study` builds a session from a saved 20–180-minute budget and common-paper or individual-subject scope. Due lesson recall comes first, then unresolved practice questions and incomplete lessons with topic drills. Reading/drill durations are estimates, not measured learning time. It never marks lessons complete or predicts readiness. Subject evidence separates lesson completion, distinct observed questions, correct, incorrect and unanswered responses, using the latest response by submission timestamp across the 30 retained attempts.

The question notebook opens from result feedback and supports a private correction note (4,000 characters), mistake reason, manually resolved state and a key/explanation doubt flag. Doubts are private, do not submit a report to anyone, and do not certify or modify a key. Flags exclude questions from focused retries until explicitly cleared. Original reports remain immutable. A later correct response clears the automatic unresolved signal; private notes remain. Filter by topic, open/resolved/doubt status, and note/question text; notebook results paginate ten per page.

Select 1–20 unresolved, non-doubtful questions for a custom retry. Only those exact released questions are reused, with one minute each, +2/−0.50 scoring and free navigation. It is not a full exam template. Active objective, personal or DEST sessions block a new retry. Same-tab launch requires matching attempt ID and writer; later recovery uses the existing explicit takeover mechanism. Settings and notes live in optional `sscStudy` inside the validated learning vault, so old backups remain valid and new JSON backups retain this work. Stale revisions reject writes rather than overwrite another tab.

Validation adds eight regression tests for journal bounds and backward compatibility, chronological response selection, reversible manual resolution, budget/scope planning, distinct subject evidence, exact retry pools/timing/ownership and validated backup/stale-write protection. The production HTTP smoke suite includes the new desk. The content/expert-review gates above still apply; this release adds study software, not independently reviewed curriculum or imported official papers.
